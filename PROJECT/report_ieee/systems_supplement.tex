\section{Slow-rate boundary check}
For periodic failed contacts with unused services, weight one, no score resets before
the first alarm, and no eviction, the recurrence is $L_n=c+e^{-\Delta/\tau}L_{n-1}$.
Its asymptote is $c/(1-e^{-\Delta/\tau})$. It crosses $\eta$ in finite time
only when that limit exceeds $\eta$ (for the parameters studied, $c<\eta$).
Figure~\ref{fig:slow} compares the analytic limit with actual detector runs for nine
gaps surrounding the prediction. Each run stops at its first alarm or at five hours;
observed peaks for detections stop at the crossing. This is a deterministic implementation
check, not an estimate of stochastic detection probability.
